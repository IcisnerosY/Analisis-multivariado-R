# Análisis Factorial Exploratorio (AFE)

Materiales correspondientes al tema **Análisis Factorial Exploratorio (AFE)** del curso **"Análisis multivariado y métodos de clasificación de datos con R"**, El Colegio de México, Centro de Estudios Sociológicos.

## Contenido

- Introducción al Análisis Factorial Exploratorio
- Diferencias entre AFE y Análisis de Componentes Principales (PCA)
- Matriz de correlaciones
- Adecuación de los datos para el análisis factorial
- Extracción de factores
- Determinación del número de factores
- Rotación de factores
- Interpretación de cargas factoriales
- Puntuaciones factoriales
- Implementación del AFE en R
